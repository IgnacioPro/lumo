# Support

## Where to Ask for Help

- Issues (bugs): https://github.com/IgnacioPro/lumo/issues
- Discussions (questions/design): https://github.com/IgnacioPro/lumo/discussions
- Docs and examples: see `README.md`, `docs/`, and `examples/`

## Before Opening a New Ticket

- Search existing issues/discussions first
- Include environment details (OS, Go version, deployment mode)
- Include clear reproduction steps and expected vs actual behavior
- Attach logs/output with secrets redacted

## Security Issues

For vulnerabilities, follow `SECURITY.md` and use private reporting.
