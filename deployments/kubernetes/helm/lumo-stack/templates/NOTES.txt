====================================================================
  Next Steps
====================================================================

1. Check deployment status:
   kubectl get pods -n {{ .Values.global.namespace }} -w

2. View API server logs:
   kubectl logs -f -n {{ .Values.global.namespace }} -l app.kubernetes.io/component=api

3. View agent logs:
   kubectl logs -f -n {{ .Values.global.namespace }} -l app.kubernetes.io/component=agent

4. Access API server (port-forward):
   kubectl port-forward -n {{ .Values.global.namespace }} svc/lumo-api {{ .Values.api.service.port }}:{{ .Values.api.service.port }}
   curl http://localhost:{{ .Values.api.service.port }}/api/v1/health

5. Check Prometheus metrics:
   kubectl port-forward -n {{ .Values.global.namespace }} svc/lumo-agent-metrics 9090:9090
   curl http://localhost:9090/metrics
